O Que É a Encriptação AES-256-GCM?

A encriptação é uma das tecnologias mais importantes utilizadas para proteger informações confidenciais. Os gestores de palavras-passe dependem da encriptação para ajudar a manter as palavras-passe armazenadas e outros dados privados protegidos. Um método de encriptação que poderá encontrar é o AES-256-GCM. Mas o que significa isso na prática?

O Que É o AES?

AES significa Advanced Encryption Standard (Padrão de Encriptação Avançada). É um algoritmo de encriptação simétrica amplamente utilizado, concebido para proteger informações através da transformação de dados legíveis numa forma encriptada.

Na encriptação simétrica, é utilizada a mesma chave secreta subjacente para encriptar e desencriptar os dados. Sem a chave adequada, as informações encriptadas não devem ser legíveis.

O AES suporta tamanhos de chave de 128, 192 e 256 bits. O AES-256 refere-se à versão que utiliza uma chave de encriptação de 256 bits.

O Que Significa o "256"?

O "256" em AES-256 refere-se ao tamanho da chave de encriptação: 256 bits.

Uma chave maior proporciona um espaço de chaves possíveis superior, tornando tentativas exaustivas de força bruta contra a chave de encriptação computacionalmente impraticáveis com os métodos conhecidos atualmente, desde que a implementação criptográfica e a gestão de chaves sejam tratadas adequadamente.

O ponto importante é que o AES-256 se refere ao tamanho da chave de encriptação e não ao tamanho dos dados que estão a ser encriptados.

O Que Significa GCM?

GCM significa Galois/Counter Mode (Modo Galois/Contador). É um modo de operação que pode ser utilizado com o AES para fornecer encriptação autenticada.

Isto é importante porque a encriptação não serve apenas para manter os dados em segredo. Um sistema também precisa de uma forma de detetar se os dados encriptados foram modificados ou corrompidos.

O AES-GCM oferece ambos:

  • Confidencialidade — ajuda a manter os dados encriptados privados.
  • Integridade e autenticidade — fornece uma etiqueta (tag) de autenticação que pode ser verificada para detetar alterações não autorizadas nos dados encriptados.

O Que É uma Etiqueta de Autenticação (Authentication Tag)?

O AES-GCM produz uma etiqueta de autenticação juntamente com os dados encriptados. Esta etiqueta permite à aplicação verificar que a informação encriptada não foi alterada desde que foi criada.

Se os dados encriptados ou as informações autenticadas associadas forem modificados, a autenticação falhará quando os dados forem desencriptados. A aplicação pode então rejeitar os dados em vez de tratar informações potencialmente modificadas como válidas.

Isto fornece uma camada de proteção importante para aplicações que armazenam dados confidenciais.

Por Que Razão Isto É Importante para os Gestores de Palavras-passe?

Os gestores de palavras-passe armazenam informações extremamente confidenciais, incluindo palavras-passe, nomes de utilizador, notas seguras e outras informações privadas.

Simplesmente guardar essas informações num ficheiro não é suficiente. Se alguém obtiver acesso ao armazenamento subjacente, as informações guardadas não devem estar disponíveis de forma legível.

A encriptação permite que um gestor de palavras-passe armazene o cofre num formato encriptado em vez de texto simples.

A encriptação autenticada também ajuda a aplicação a detetar modificações inesperadas nos dados encriptados do cofre.

A Encriptação Não Substitui uma Palavra-passe Mestre Forte

Uma encriptação forte é uma parte importante da proteção de um gestor de palavras-passe, mas não elimina a importância de proteger a chave utilizada para aceder aos dados encriptados.

Uma palavra-passe mestre forte e única é, portanto, uma componente crucial de uma estratégia global de segurança para um gestor de palavras-passe.

Os utilizadores também devem proteger os seus computadores, manter o seu sistema operativo e software de segurança atualizados, e adotar práticas sensatas de cópias de segurança.

AES-256-GCM e Encriptação Local

A encriptação pode ser utilizada independentemente de o gestor de palavras-passe armazenar o seu cofre localmente ou utilizar infraestrutura na nuvem. A distinção importante é onde os dados encriptados são armazenados e como as chaves são geridas.

Com um gestor de palavras-passe local, o cofre encriptado pode permanecer no próprio computador do utilizador em vez de ser enviado para um serviço remoto. Isto pode ser útil para quem prefere que o seu cofre de palavras-passe permaneça inteiramente sob o seu controlo local.

O Que o AES-256-GCM Não Significa

O AES-256-GCM é um componente criptográfico. A sua utilização não torna automaticamente uma aplicação segura.

A segurança geral de uma aplicação também depende de como as chaves de encriptação são derivadas e protegidas, como os dados encriptados são geridos, como a autenticação é implementada, como as cópias de segurança são protegidas e como o restante da aplicação é concebido.

Em outras palavras, o algoritmo é apenas uma parte de um panorama de segurança mais amplo.

AES-256-GCM no KeenPassword Vault

O KeenPassword Vault utiliza o AES-256-GCM para encriptar o cofre local no computador Windows do utilizador. O cofre é protegido localmente em vez de ser enviado para um serviço na nuvem.

O KeenPassword Vault foi concebido como um gestor de palavras-passe offline, pelo que os dados do seu cofre permanecem no seu computador. A aplicação não requer uma conta online, sincronização na nuvem nem uma subscrição.

A camada de encriptação faz parte de um design de segurança mais abrangente que inclui armazenamento local, uma palavra-passe mestre, cópias de segurança encriptadas e funcionalidades destinadas a ajudar os utilizadores a protegerem o seu cofre.

Resumo

O AES-256-GCM combina a encriptação AES com um modo de encriptação autenticada. O AES-256 fornece uma chave de encriptação de 256 bits, enquanto o GCM fornece encriptação autenticada que ajuda a detetar modificações não autorizadas nos dados encriptados.

Para um gestor de palavras-passe, estas capacidades são úteis porque a aplicação precisa de proteger informações confidenciais, ao mesmo tempo que precisa de conseguir detetar quando os dados encriptados deixam de ser válidos.

No entanto, a encriptação é apenas uma parte da segurança de um gestor de palavras-passe. Palavras-passe fortes, gestão segura de chaves, cópias de segurança protegidas e uma boa conceção da aplicação contribuem para a segurança global de um cofre de palavras-passe.
