Perché non dovresti mai riutilizzare le password

Utilizzare la stessa password per più account può trasformare una singola password compromessa in un problema su diversi servizi. Ecco perché le password uniche sono importanti e come un gestore di password può renderle più facili da gestire.

Perché il riutilizzo della password è un problema?

Riutilizzare la stessa password su più account è comodo, ma crea un collegamento tra tali account. Se qualcuno ottiene la tua password da un servizio, potrebbe provare la stessa password su altri siti web.

Ciò significa che un incidente di sicurezza che coinvolge un account può potenzialmente mettere a rischio diversi altri account.

L'uso di una password diversa per ogni account importante rimuove quel collegamento diretto.

Come avviene il riutilizzo della password?

Il riutilizzo della password è comprensibile. La maggior parte delle persone possiede numerosi account online e ricordare una password complessa e diversa per ogni servizio può essere difficile.

Una persona potrebbe creare una sola password e utilizzarla per e-mail, acquisti, social media, intrattenimento e altri siti web. Un altro approccio comune consiste nel creare una password di base e apportarvi piccole modifiche per account diversi.

Sfortunatamente, queste variazioni possono comunque lasciare gli account collegati se un malintenzionato riesce a individuare lo schema sottostante.

Che cos'è il Credential Stuffing?

Il credential stuffing è una tecnica di attacco in cui i malintenzionati utilizzano nomi utente e password ottenuti da una fonte e tentano di utilizzare tali credenziali per accedere agli account su altri servizi.

Sfrutta proprio il riutilizzo delle password. Se una password esposta in una violazione dei dati viene utilizzata anche su un altro sito web, il secondo account può diventare un bersaglio.

I malintenzionati non hanno necessariamente bisogno di sapere quali siti web una persona utilizza. Strumenti automatizzati possono testare grandi quantità di credenziali rubate contro altri servizi online.

Una password dovrebbe proteggere un solo account

Un semplice principio di sicurezza è utilizzare una password unica per ogni account.

Se una singola password viene esposta, il potenziale impatto è quindi limitato all'account associato a quella password, anziché estendersi automaticamente a tutti gli altri account che utilizzano le stesse credenziali.

Questo è particolarmente importante per gli account che forniscono l'accesso a altri servizi, come il tuo account e-mail principale.

Perché il tuo account e-mail è particolarmente importante

Il tuo account e-mail principale può essere collegato a molti altri servizi online. Può essere utilizzato per reimpostare le password, ricevere notifiche di sicurezza e verificare la tua identità.

Riutilizzare la password della tua e-mail altrove può quindi creare un rischio aggiuntivo. Una password ottenuta da un servizio non correlato potrebbe potenzialmente essere provata contro il tuo account e-mail.

Utilizzare una password unica per il tuo account e-mail è una parte importante per separare i tuoi account online l'uno dall'altro.

Cambiare un solo carattere non è sufficiente

Alcune persone evitano l'esatto riutilizzo della password creando versioni leggermente diverse della stessa password.

Ad esempio, si potrebbe usare una password per un sito web e cambiare un numero o aggiungere il nome del servizio per un altro sito web.

Sebbene queste password siano tecnicamente diverse, gli schemi prevedibili possono comunque renderle più facili da indovinare se una delle password originali diventa nota.

Le password veramente uniche non dovrebbero essere semplicemente variazioni della stessa password di base.

Cosa rende buona una password unica?

Una buona password per un account dovrebbe essere sufficientemente lunga, difficile da indovinare e unica per quell'account.

Evita di utilizzare:

  • Parole comuni o password comuni
  • Informazioni personali
  • Sequenze prevedibili
  • La stessa password usata su un altro sito web
  • Semplici variazioni di un'altra password

Le password generate casualmente possono essere particolarmente utili perché non hanno bisogno di essere memorizzate quando un gestore di password le conserva al posto tuo.

Perché le password uniche sono così difficili da gestire?

Il problema di solito non è capire che le password dovrebbero essere uniche. La sfida è ricordarle tutte.

Se disponi di dozzine di account online, creare una password forte e diversa per ogni account e ricordarle tutte manualmente è poco pratico.

Questo è uno dei motivi principali per cui esistono i gestori di password.

In che modo aiuta un gestore di password

Un gestore di password ti consente di memorizzare una password diversa per ogni account senza richiederti di memorizzare ogni singola password.

Invece di ricordare dozzine di credenziali, in genere devi solo ricordare la password utilizzata per sbloccare la tua cassaforte di password.

Molti gestori di password possono anche generare password casuali per nuovi account, rendendo facile creare credenziali uniche senza doverle inventare tu stesso.

Cosa succede se una delle tue password viene violata?

Se un servizio che utilizzi subisce una violazione dei dati e la tua password viene esposta, dovresti cambiare quella password non appena possibile e seguire qualsiasi guida di sicurezza fornita dal servizio interessato.

Se hai riutilizzato quella stessa password su altri siti web, anche quegli account dovrebbero essere considerati potenzialmente interessati. Cambia la password riutilizzata anche su quei servizi e sostituiscila con una password unica.

Se ogni account utilizza già una password diversa, una password compromessa non fornisce automaticamente la stessa credenziale per i tuoi altri account.

Dovresti cambiare ogni password regolarmente?

Cambiare regolarmente ogni password semplicemente perché è passato del tempo non è necessariamente l'approccio più utile quando le password sono già forti e uniche.

Invece, presta particolare attenzione alle situazioni in cui una password potrebbe essere stata esposta, compromessa o riutilizzata.

Quando si sa o si sospetta che una password sia stata compromessa, è importante cambiarla tempestivamente.

E le passkey?

Le password non sono l'unico modo per autenticarsi ai servizi online. Alcuni siti web e applicazioni ora supportano le passkey, che utilizzano credenziali crittografiche anziché password tradizionali.

Le passkey possono ridurre o eliminare alcuni dei problemi associati al riutilizzo delle password perché sono progettate in modo diverso dalle password tradizionali.

Tuttavia, le password rimangono ampiamente utilizzate e le buone pratiche per le password sono ancora rilevanti per i molti servizi che vi fanno affidamento.

Considerazioni finali

Il riutilizzo delle password crea un collegamento tra i tuoi account. Se una password riutilizzata viene esposta, i malintenzionati potrebbero provarla contro altri servizi in cui utilizzi le stesse credenziali.

L'uso di una password unica per ogni account aiuta a prevenire che una singola password compromessa diventi automaticamente la chiave per gli altri account.

La sfida è ricordare tutte quelle password uniche. Un gestore di password risolve questo problema memorizzando in modo sicuro le tue credenziali e consentendoti di utilizzare password forti e uniche senza dover memorizzare ciascuna di esse.
